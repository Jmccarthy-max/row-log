# Row Log — OARS 🚣

A phone-friendly, offline training tracker for an OARS (Orlando Area Rowing Society) rower.

**Use it:** open the site, then in Safari: Share → **Add to Home Screen**. All data (workouts, food, water, photos) is stored on the device only.

- 🚣 Erg & on-water rowing log with auto /500m splits, PR tracking, and a split-progress chart
- 🏋️ Coach Jenn's 3-day lifting split with form notes and how-to video links
- 🍽️ Food log + Coach Jenn's race-week nutrition plan
- 💧 Water tracking by 32 oz bottles
- 🏁 Racing-season awareness (sprint / head race / winter / summer)
- 💡 Searchable coaching tips and daily quotes

Built with plain HTML/CSS/JS in a single file (`index.html`).
